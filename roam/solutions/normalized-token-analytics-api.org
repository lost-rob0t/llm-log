#+title: Normalized token capture and analytics API
#+filetags: :llm-log:solution:analytics:

* Solves
[[id:0750164e-ceb8-4415-a660-0ea5f9c19b1f][Provider-neutral token analytics]]

* Approach
Normalize authoritative response counters into =input_tokens=, =output_tokens=, and =total_tokens= when recording each event. Extract known OpenAI-compatible, Anthropic, Gemini, Cohere, and Ollama field shapes without depending on provider names. For streamed responses, retain maxima rather than summing cumulative counters.

Expose read-only summary, UTC timeline, and provider/model grouping endpoints from the capture service. Report request coverage separately so records with unknown or partial usage remain visible.
