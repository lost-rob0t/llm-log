* Architecture evidence
The Common Lisp expert service extends immutable usage projections with optional explicit =attempt_id=, =attempt_ordinal=, =retry_of_request_id=, =client=, and =transport= evidence. Validation rejects non-positive attempt ordinals and self-referential retry predecessors.

=query_task_accounting= derives counts and provenance only from the same bounded task subtree and =usage-task-id= Tek9 candidates already used by task accounting. It does not scan the corpus, infer retries from timing/session adjacency, reprice historical requests, or add a Python/Common Lisp rule engine. SWI-Prolog remains the owner of pricing inference.

No Tek9 repository mutation was required; existing durable document/index primitives remain sufficient.
