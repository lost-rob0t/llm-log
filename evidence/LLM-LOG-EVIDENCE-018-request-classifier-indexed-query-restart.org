- History retrieval requires a finite =limit= (service maximum 64) and at least one selective equality filter.
- The service uses existing Tek9 secondary indexes and =select-index-range= with explicit bounds/candidate caps; it never falls back to whole-corpus =select= for this operation.
- Source evidence remains separate from derived assertion records. Query results join bounded source metadata to classifier assertions through the source-event provenance index.
- Classification history remains queryable after the Common Lisp expert host is stopped and restarted against the same Tek9 directory.
- Returned records preserve assertion/source/rule/expert provenance.
- Empty unbounded history queries are rejected rather than scanned.
- SWI-Prolog owns explicit ambiguity rules; the ambiguity fixture produces competing same-dimension =state=ambiguous= assertions.
- Classification metadata grants no authority.
- Python remains capture/transport and its expert fail-open/fail-closed policy tests remain GREEN.
