* Architectural evidence
The implementation is confined to the Common Lisp dataset projection. It resolves request usage through the existing =usage-request-id= exact index and reuses #13's bounded =query-task-accounting= projection with fixed depth/node ceilings. Task projections are cached by =task_id= for the lifetime of one dataset query.

No pricing is recomputed in the exporter. Numeric bounds only match complete =known= task accounting in the requested coherent currency; =partial= and =unknown= remain explicit states and are never promoted into exact numeric totals. The exporter does not invoke SWI-Prolog, so historical cost/outcome assertions retain the rule/pricing provenance present when they were created.

No Tek9 repository primitive was added. No Python capture/transport behavior changed. No dotfiles consumer configuration changed. Proxy forwarding/fail-open semantics are unaffected.
