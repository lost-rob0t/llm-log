The implementation adds a bounded =reasoner-failure= condition with read-only =kind= and =message= metadata. Runtime classifications are finite:
- =:unavailable=
- =:crashed=
- =:timeout=
- =:malformed-reply=

Malformed JSON, reply shape/status errors, and request/operation correlation errors now classify as =:malformed-reply=. EOF classifies as =:crashed=. The bounded deadline classifies as =:timeout=. Worker launch/liveness failure classifies as =:unavailable=.

The service maps those runtime classes to stable protocol error codes rather than collapsing them into =fixture_error=:
- =reasoner_unavailable=
- =reasoner_crashed=
- =reasoner_timeout=
- =reasoner_malformed_reply=
