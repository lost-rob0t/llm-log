* Design reconciliation during implementation
Initial ARADR considered copying =started_at= into classifier-source projections. Source inspection rejected that mutation: request-event projections already own immutable =started_at= evidence and the existing Tek9 =classification-source-started-at= ordered index keys those event documents. Duplicating the field would create unnecessary classifier-source schema/replay risk.

RESEARCH-038 was updated before final implementation to require a bounded event-index -> classifier-source point join instead.
