* Mutable-state correction
The reusable llm-log default mutable state root is =~/.llm-proxy=.

The expert service default is derived from that configured root:

#+begin_example
~/.llm-proxy/expert/
#+end_example

This is a default, not a hard-coded personal location. Standalone config/CLI and Home Manager may override the llm-log data root. The consumer dotfiles intentionally configure:

#+begin_example
~/Documents/AI/proxy
#+end_example

so that machine's expert state may resolve beneath =~/Documents/AI/proxy/expert/= without changing reusable defaults.

No mutable state belongs in the Nix store.
