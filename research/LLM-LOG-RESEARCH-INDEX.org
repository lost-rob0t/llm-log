* Hard rules every contributor must know
1. Zero Python in the accepted implementation. No shims, no Python test
   harness, no second rule engine in Common Lisp.
2. RED-first: the contract must be committed and proven failing before the
   implementation is committed; GREEN is only claimed with an observed run on
   the exact head.
3. Every Nix-run SBCL entrypoint loads the wrapper-provided ASDF
   (=$ASDF=) before anything else. See [[file:LLM-LOG-RESEARCH-014-configuration-and-operations.org][014]], troubleshooting.
4. Raw capture is immutable evidence; secrets are forwarded but redacted
   before persistence; derived assertions never overwrite history.
5. SWI-Prolog stays the sole inference engine; Tek9 stays the canonical
   durable KB; Common Lisp owns orchestration only.
