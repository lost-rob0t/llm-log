* Hard rules every contributor must know
1. Maintained implementation is Common Lisp. Do not add Python shims, adapters,
   CLIs, tests, services, or packaging.
2. Local capture, bulk-load, infill, analytics, and expert calls stay in-process
   or direct Common Lisp; HTTP is only an optional separate-server deployment
   boundary.
3. Raw capture is immutable evidence. Giant bodies stay in =events.jsonl=;
   Tek9 stores bounded derived projections and provenance.
4. Large-corpus checkpoints are byte offsets and advance only after successful
   durable projection.
5. SWI-Prolog remains the sole rules/inference engine; Tek9 remains canonical
   derived storage; Common Lisp owns lifecycle, materialization, validation,
   transport, and persistence boundaries.
6. Missing provider usage is unknown; never estimate token counts.
7. HTTP/provider completion alone is not task success.
