* Tek9 transaction decision
No new Tek9 primitive is required for this slice.

Tek9's existing public =with-write-transaction= composes nested =fetch*= and =put*= calls on the same database into one LMDB write transaction. Therefore event projection and KB-revision mutation can be atomic without modifying Tek9.

The substrate uses stable keys:
- =event:<event-id>= for projected events;
- =meta:kb-revision= for the durable revision counter.

Replay semantics:
- missing event -> create projection and increment revision once;
- equivalent event -> return =existing= and leave revision unchanged;
- contradictory event -> =event_conflict= and abort without overwriting evidence.

The event projection deliberately stores only bounded metadata and raw-corpus references/hashes. Prompt and response bodies remain in append-only capture evidence.

* Common Lisp supervisor decision
One =expert-host= owns exactly one SWI-Prolog child process at a time.

Implementation commits in this transaction include:
- =580f80b3= initial Common Lisp Prolog supervisor;
- =63f0cfae= explicit packaged worker-path override;
- =730c7874= host lifecycle owns Tek9 plus the persistent worker.

The CL -> Prolog protocol remains JSON-lines over private stdio and has a closed operation set:
- =health=
- =event_transport=

There is no generic goal operation. Model/user-controlled values are serialized as JSON data and never converted into callable Prolog terms.

Each worker request carries a generated correlation ID. Common Lisp validates correlation ID, operation and status before accepting a reply. A broken/malformed worker exchange invalidates the current worker rather than manufacturing a successful inference.

* Adversarial review
** Duplicate/racing evidence
Projection + revision mutation uses one Tek9 write transaction. Equivalent replay is non-mutating; contradictory replay fails closed.

** Process-local state masquerading as truth
Rejected. The Prolog session ID is ephemeral. Event projections and KB revision are durable Tek9 state and survive worker/service restart.

** Arbitrary Prolog execution
Rejected twice: public service operations are closed, and private worker operations are closed. No =call_prolog= / arbitrary goal path exists.

** Whole-corpus materialization
Rejected. =event_transport= does one exact Tek9 point lookup and supplies one normalized value to Prolog.

** Nix source-tree dependency
Rejected. Packaging supplies an explicit immutable worker path. Mutable state is never written into the Nix store.

** False success claims
No local SBCL/SWI/Nix execution is available in this cycle. The new flake check defines the executable gate but is not claimed GREEN until actually run on the exact head.
