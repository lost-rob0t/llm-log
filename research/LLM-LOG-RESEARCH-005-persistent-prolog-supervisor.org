* Supervisor ownership
Common Lisp owns the SWI-Prolog process and all process lifecycle semantics.

One =expert-host= owns at most one live SWI-Prolog worker at a time. Queries reuse that worker. A worker crash invalidates the session ID, returns an explicit typed failure for the in-flight operation, and permits a bounded restart before a later operation. No query may spawn an independent one-shot Prolog interpreter.

The Prolog worker is not the database. Tek9 remains canonical durable state. Prolog receives only bounded facts required for the declared operation.

* Closed Prolog protocol
The CL -> Prolog protocol is JSON-lines over private stdio.

Allowed worker operations for this slice:
- =health=
- =event_transport=

There is no generic goal field and no =call= operation.

Each message includes:
- protocol version;
- correlation/request ID;
- operation atom selected by Common Lisp code;
- normalized data object.

The worker replies with:
- status =ok|error=;
- request ID;
- operation;
- rule version;
- deterministic result or structured error.

User/model strings are serialized only as JSON values. They are never parsed with =read_term/3=, =term_string/2=, =atom_to_term/3=, or passed to =call/1=.

* Tek9 projection contract
For the substrate proof, event documents use stable primary keys of the form =event:<event-id>=.

The value contains only expert-plane metadata/references needed for inference:
- event ID;
- provider/upstream when present;
- model when present;
- transport;
- started/completed timestamps when present;
- request/response hashes or durable raw-corpus references;
- projection schema version.

Raw request/response bodies stay in the append-only capture corpus and are not copied into Tek9 merely for this expert substrate.

Replay rule:
1. If =event:<id>= does not exist, create it and advance the KB revision once.
2. If it exists with equivalent projected data, return =existing= and do not advance revision.
3. If it exists with contradictory projected data, return a typed =event_conflict= error. Do not overwrite evidence silently.

KB revision is durable metadata in Tek9, not an in-memory process counter.

* Fixture derivation
The first declared expert predicate is =event_transport=.

Common Lisp fetches exactly one event document by stable primary key, extracts its normalized transport value, and sends only that bounded fact to SWI-Prolog. SWI-Prolog applies a fixture rule and returns the transport plus =fixture.event_transport/v1=.

The externally returned result includes:
- expert =fixture.event_transport=;
- value;
- derivation_type =deterministic=;
- rule_version;
- KB revision;
- evidence IDs containing the source event ID;
- Prolog session ID.

This fixture proves the substrate only. It must not grow into the production request classifier.

* Failure semantics
** Prolog unavailable at expert-service start
The expert service reports a typed unavailable/error state. The llm-log proxy remains fail-open unless =require_expert_plane= is explicitly enabled.

** Worker crash during a query
Return typed =reasoner_crashed= for the operation. Do not manufacture an empty result. Mark the session dead and permit a bounded restart for subsequent operations.

** Timeout
Terminate/restart the stuck worker and return =reasoner_timeout=. Never let an unbounded Prolog query stall transparent proxy forwarding.

** Malformed Prolog reply
Return =invalid_reasoner_reply= and discard it. Never persist a derived assertion from an invalid reply.

** Duplicate event
No mutation and no KB revision increment.

** Contradictory duplicate
Return =event_conflict=; preserve the existing immutable projection.

* Adversarial review
** Arbitrary Prolog execution
Rejected by a closed dispatcher on both CL and Prolog sides. No model-controlled callable terms.

** Whole-corpus materialization
Rejected. The fixture path uses one Tek9 primary-key fetch. Future experts must add explicit indexes/bounded graph neighborhoods before broader queries.

** Lost idempotency on restart
KB revision and event projection live in Tek9, so process restart does not reset duplicate detection.

** Reasoner becomes canonical state
Rejected. SWI-Prolog is disposable reasoning state; Tek9 remains durable authority.

** False-green inference
A valid transport/HTTP response is not task success. This substrate fixture only proves transport metadata derivation and must not be reused as outcome evidence without explicit rules later.
