* Analyze

* Design
1. Keep one local Nix package expression for Sento rather than embedding the dependency stanza repeatedly in =flake.nix=.
2. Pin upstream =mdbergmann/cl-gserver= to commit =013ab6370042686e65943568b0d97e33319c0f54= and fixed hash =sha256-z+AKk8Y09rpF+NgyKhcHNvn0jsjeGe3dSibkv8yySKg==.
3. Package only the =sento= runtime ASDF system; do not pull =sento/tests=, remoting, docs, or benchmarks into the recorder runtime.
4. Bind the package's =lispLibs= only to the declared runtime dependency closure.
5. Export the package through the flake and use an SBCL closure carrying Sento for =common-lisp-recorder-deps=.
6. Preserve the *identical* =(asdf:load-system :sento)= RED/GREEN check.
7. With packaging GREEN, the next independent slice may declare Sento in the runtime/test systems and implement the already-RED RESEARCH-018 recorder API.
