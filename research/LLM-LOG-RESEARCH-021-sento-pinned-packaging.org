* Design
1. Add one local Nix package expression for Sento rather than embedding a large dependency stanza repeatedly in =flake.nix=.
2. Pin upstream =mdbergmann/cl-gserver= to commit =013ab6370042686e65943568b0d97e33319c0f54= and a fixed source hash.
3. Package only the =sento= runtime ASDF system; do not pull =sento/tests=, remoting, docs, or benchmarks into the recorder runtime.
4. Bind the package's =lispLibs= only to the declared runtime dependency closure.
5. Add the resulting package to the SBCL closure used by =common-lisp-recorder-deps=.
6. Rerun the *identical* =(asdf:load-system :sento)= check. No weakening or replacement of the RED contract is allowed.
7. Only after GREEN may the expert runtime/test systems declare Sento and implement the RESEARCH-018 recorder API.

* Adversarial review
** Moving Git branch or unpinned tarball
Rejected. Actor runtime semantics must not drift underneath an evidence chain.

** Ambient Quicklisp at build or runtime
Rejected. This would make Home Manager/systemd deployment non-reproducible and would violate the existing flake contract.

** Vendor all transitive sources into llm-log
Rejected unless a dependency is genuinely unavailable through the pinned Nixpkgs Lisp package set. Prefer existing reusable packages first.

** Pull Sento tests/remoting into production closure
Rejected. The recorder needs the core actor runtime only.

** Implement recorder before dependency GREEN
Rejected. It would make failures ambiguous between packaging and behavior.

** Modify Tek9
Rejected for this slice. Recorder persistence remains raw evidence storage below the symbolic KB boundary; no missing Tek9 primitive has been demonstrated.

** Update dotfiles to this branch
Rejected. The consumer remains on its stable merged revision until llm-log exposes a merge-ready runtime.

* Decision
Package pinned Sento 3.4.4 as a first-class Nix/SBCL dependency, using existing Nixpkgs Common Lisp libraries wherever available. Preserve the exact dependency RED as the GREEN gate. Do not implement recorder behavior until that gate passes.
