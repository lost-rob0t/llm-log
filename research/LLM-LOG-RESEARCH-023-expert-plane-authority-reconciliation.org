* Design
The next bounded #10 contract SHALL exercise the real Common Lisp -> Tek9 -> SWI-Prolog substrate rather than transport migration.

Minimum typed integration contract:
1. create one temporary expert host with one Tek9 environment;
2. persist a typed source observation in Tek9;
3. retrieve it by an explicit bounded/indexed lookup rather than corpus scan;
4. materialize only the declared facts for the test observation;
5. invoke the declared =event_transport= Prolog operation through the persistent worker;
6. validate protocol version, request correlation, operation, status and bounded result shape;
7. persist the derived assertion separately from the immutable source evidence with source ID, rule/version and expert/version provenance;
8. verify a second request reuses the live worker/session;
9. verify an unknown operation is rejected before any callable Prolog term is constructed;
10. verify timeout/crash invalidates the in-flight request and no implicit replay occurs.

The test must use a temporary database and fixture worker/rules. It must not require or load the full capture corpus.

* Local protocol
Keep the versioned observation/query boundary from RESEARCH-004. Python sends typed observations and consumes typed results. It does not execute expert rules.

Fail-open remains the proxy default when the expert service is absent or invalid. =require_expert_plane= is the explicit fail-closed mode.

* Provenance separation
- Raw capture evidence: immutable and Python-owned.
- Derived Tek9 assertions: expert-owned, source-linked, versioned and supersedable.
- Research/design: files under =research/=, including this file.
- Implementation/test evidence: files under =evidence/=; never substitute a prose claim for executed RED/GREEN evidence.

Credentials are excluded from Tek9 facts, Prolog facts, Nix strings, research prose and logs unless explicitly intended and safely redacted.

* Nix and non-Nix
The existing flake remains the reproducible Nix path for SBCL, Tek9 and SWI-Prolog. The same Common Lisp service contract must remain launchable outside Nix with ordinary runtime configuration and an explicit worker path override.

The dotfiles consumer remains configuration-only and preserves =~/Documents/AI/proxy=; no consumer mutation is required for this substrate slice.
